AI Project Planner (Groq + Streamlit)
An AI‑powered project planning assistant that generates structured project plans, timelines, risks, and exportable documentation using Llama 3.3‑70B via Groq.

🚀 Features
AI‑generated project plans

Gantt chart timeline

Risk matrix

Save & load plans

Export to PDF & JSON

Clean dashboard UI

Dark theme styling

🧠 Powered by Groq Llama 3.3‑70B
This app uses Groq’s ultra‑fast inference to generate structured JSON project plans from natural language descriptions.

🛠️ Tech Stack
Streamlit

Groq LLMs

Plotly

FPDF

Python 3.10+

📦 Installation
bash
git clone https://github.com/<your-username>/AI-Project-Planner.git
cd AI-Project-Planner
pip install -r requirements.txt
Create .env:

Code
GROQ_API_KEY=your_key_here
Run the app:

streamlit run app.py
